# PDF answers and page references

The Python app accepts text-based PDFs through Add document (2 MB, up to 100 pages and 100,000 extracted characters). Each page is split independently. Returned source metadata contains the original physical PDF page number, starting at 1, document title and exact extracted excerpt. Clicking [1] highlights its source card; this is not an embedded PDF viewer. Printed page labels can differ from physical PDF page numbers. TXT/MD use chunk references, never invented page numbers.

Scanned, encrypted, malformed PDFs and pages without extractable text are rejected with an explanation. OCR and Word documents are not supported. Existing text documents remain compatible; no database migration is required. Re-upload previously pasted PDF text as a PDF to obtain page provenance.

The browser-only hosted review does not parse PDFs; use the Python backend. Set AI_MODE=azure and configure the provider for generated answers. Preview mode returns excerpts. Questions without sufficient retrieved evidence return a no-evidence response. Model answers and relevance are not guaranteed; verify excerpts. Page metadata is assigned by the parser, not generated by AI.
